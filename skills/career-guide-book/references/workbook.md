# Workbook structure

## Page plan

Give each physical page a purpose, an anticipated page number, and an observable reader outcome. Map milestone dependencies before drafting. The following is a 50-page starting plan.

| Pages | Content |
| --- | --- |
| 1–4 | Cover with the first useful action and print instructions, linked milestone map, starting-point worksheet, and how to use the guide |
| 5–36 | 16 two-page milestone pairs for the reader's progression |
| 37–44 | Eight reusable worksheets that match the tasks in the guide |
| 45–50 | Field-specific resources, next moves, and source register |

For fewer pages, combine the cover and orientation or combine a lesson and its action on one page. Preserve enough writing room. For a one-page request, provide a useful condensed guide with embedded source notes. For more pages, add worked examples, deeper practice, decision branches, and reusable tools. Prefer changing the scope or adding meaningful material over scaling the type or padding the book. An odd page count is valid for duplex printing.

## Milestone pair

- **Lesson.** State the decision or skill, why it matters at this stage, any prerequisites, and one field-specific example. Show what a reasonable first attempt looks like.
- **Action.** Start with an achievable task and a realistic time box where useful. Include ordered actions, supplies or inputs, and room to record the outcome.
- **Evidence to save.** Name a concrete artifact such as a work sample, practice log, budget, decision note, or verified contact list.
- **Readiness checkpoint.** Give the reader a criterion they can assess with that artifact and a next step if they meet it. If they are waiting for permission, feedback, a reply, or resources, name useful parallel work they can do.

Adapt stages to the profession and reader. Common stages include orientation, prerequisites, deliberate practice, evidence of skills, supervised or entry-level work, and a review of next steps. Use estimated time ranges when reasonable. Preserve progression without promising employment or certification.

## Reusable worksheets

Label the purpose and connect the worksheet from the corresponding action page. Make each usable by itself when photocopied. Offer meaningful fields, such as date, task, evidence saved, what changed, and next action, with enough handwriting room. Vary the actual tools by task. A practice log, outreach tracker, cost planner, and decision rubric serve different jobs.
