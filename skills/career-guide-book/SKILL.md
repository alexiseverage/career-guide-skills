# Career guide book

Produce a workbook a reader can act on, write in, and use at their own pace. Default to a **50-page PDF and self-contained editable HTML**. Treat a user-specified page count as the final physical PDF page count, including cover, contents, worksheets, and sources. A separate companion file does not count toward it.

1. Establish the career goal, reader's starting point, and jurisdiction where the advice depends on location. Use information the reader already supplied. Ask for missing facts only when they materially change the book. Offer the optional aesthetic in the same intake and follow [aesthetic integration](references/aesthetic.md).
2. Build the page plan using [workbook structure](references/workbook.md). Each milestone normally pairs an instructional page with an action page. Give the reader an artifact to save, a readiness checkpoint, and something useful to do if blocked. For longer guides, deepen demonstrations and practice. For shorter ones, combine material and reduce the number of milestones.
3. Apply [research and evidence rules](references/research.md). Ground current requirements and opportunities in dated sources. Turn findings into actions with examples. Clearly label fictional worked examples, illustrative costs, and estimates.
4. Draft the full workbook, including useful writing space and a source register. If the user also requests a local directory, use `local-opportunity-directory` when available and keep it a separate deliverable unless the user asks to combine it. Share any relevant brief, geography, and chosen style across the outputs.
5. Follow [print and delivery](references/print.md) to build, render, inspect, and reconcile the PDF and source. Verify the rendered page count and fix the layout or page plan until it matches the target. If rendering or inspection is unavailable, deliver the editable source or manuscript and say which checks are pending.
