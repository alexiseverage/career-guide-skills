# Listing structure

Open with the directory's purpose, public origin or area, distance method and units, the date checked, and a short explanation of how to use the directory. Give the count by status and note what the research covered. Describe the result as exhaustive only when coverage can be demonstrated.

Group candidates by evidence and career relevance. A useful order is confirmed openings, high-fit leads, and other leads with a clear case for contacting them. Where useful, put unresolved candidates in a separate research queue and exclude them from the verified counts. Within a group, use a declared sort such as proximity or application deadline.

## Listing fields

| Field | Include |
| --- | --- |
| Name and status | Public business or program name and clear evidence status |
| Location | Public address or locality, with verified distance and units where applicable |
| Public contact | Preferred professional inquiry channel and a fallback where verified |
| Evidence and next move | Why it belongs in this directory, relevant dated evidence, and one appropriate next action |
| Source | Linked visible label or short source ID, date checked, and closing date if applicable |

Keep an entire listing together on the page where possible. Carry group names and repeated column headings across pages when needed. Footnote secondary facts and label unknown fields as such. Avoid copying promotional bios or full job listings. If the user provides a hard page cap, prioritize eligible listings, report the omitted count and selection method, and provide a separate full register when useful. When a directory has no verified listings, provide the search scope and an outreach or research worksheet instead.

If an outreach tracker is useful, leave room for organization, date, contact route, outcome, and next follow-up. Use text labels and ruled space so it remains useful in black and white.
